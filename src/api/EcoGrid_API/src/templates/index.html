Credenciales de APIs & Acciones Pendientes

Red Eléctrica de España (REE / ESIOS)

Para habilitar acceso oficial a la API de e-sios V2 con granularidad de alta frecuencia:

  1. Enviar solicitud a consultasios@ree.es solicitando un Personal API Token para la plataforma e-sios.
  2. Añadir el token recibido al archivo .env en la variable ESIOS_API_TOKEN=tu_token_aqui.
  3. Nota operativa: El conector implementa fallback transparente al endpoint público oficial de REE (apidatos.ree.es) cuando el token no está configurado.

Open-Meteo Weather API

Activo y en producción. Consulta variables horarias completas para Madrid sin requerir clave de API para uso de desarrollo.

OMIE (Operador del Mercado Ibérico de Energía)

Descarga directa diaria de ficheros de precios marginales horarios (marginalpdbc) y curvas agregadas de oferta y demanda.
